# 찌봄 — 스마트폰 카메라 찌 감지 웹앱 MVP

스마트폰 카메라가 낚시찌를 계속 보고, 평소 물결보다 큰 움직임이 생기면 소리와 진동으로 알려주는 정적 웹앱입니다.

## 바로 실행하기

별도의 설치나 빌드가 필요 없습니다.

```bash
cd jjibom-webapp
python3 -m http.server 8080
```

컴퓨터 브라우저에서 `http://localhost:8080`을 여세요.

- 카메라 없이 확인: **데모 체험** 버튼
- 실제 카메라 사용: **카메라 켜기** 버튼
- 휴대폰에서 실제 카메라를 쓰려면 HTTPS로 배포해야 합니다.
- GitHub Pages, Netlify, Vercel 같은 정적 호스팅에 폴더 그대로 올릴 수 있습니다.

## 사용 순서

1. 휴대폰을 삼각대나 거치대에 단단히 고정합니다.
2. 카메라를 켭니다.
3. 화면에서 찌 끝의 빨강·주황·형광색 부분을 터치합니다.
4. 약 2~3초 동안 평소 물결을 보정합니다.
5. **감시 시작**을 누릅니다.
6. 큰 하강·상승·떨림·찌 사라짐이 감지되면 알람이 울립니다.

## 들어 있는 기능

- 후면 카메라 우선 연결 및 전·후면 전환
- 사용자가 터치한 찌 색상 자동 채취
- 색상과 이전 위치를 함께 이용한 실시간 찌 추적
- 평소 물결 크기 자동 보정
- 하강, 상승, 연속 떨림, 찌 잠김/사라짐 감지
- 민감도 1~10 조절
- 야간 LED찌 추적 모드
- 소리와 진동 알람
- 화면 자동 꺼짐 방지 기능
- 입질 기록과 정탐/오탐 피드백
- 오탐 피드백을 이용한 로컬 민감도 미세 보정
- 카메라 없이 시험하는 가상 낚시터 데모
- 홈 화면 설치가 가능한 PWA 구성
- 오프라인 앱 화면 캐시

## 감지 방식

서버로 영상을 보내지 않고 브라우저 안에서 처리합니다.

```text
카메라 프레임
→ 사용자가 선택한 색과 가까운 픽셀 찾기
→ 이전 위치 주변에서 찌 중심 계산
→ 평소 위치와 비교
→ 이동 거리·속도·보이는 면적·떨림 횟수 계산
→ 임계값을 넘으면 알람
```

분석용 영상은 최대 약 320픽셀 크기로 줄여 처리하므로 휴대폰 부담을 낮췄습니다. 원본 카메라 영상이나 입질 영상은 서버에 업로드하지 않습니다.

## 실전 사용 전에 알아둘 점

이 버전은 제품 검증용 MVP입니다. 다음 환경에서는 찌를 놓치거나 오탐이 생길 수 있습니다.

- 폰이나 거치대가 움직이는 경우
- 찌가 화면에서 너무 작은 경우
- 찌와 배경 물결의 색이 비슷한 경우
- 강한 햇빛 반사가 찌와 같은 색으로 보이는 경우
- 다른 낚싯줄이나 물체가 찌 앞을 가리는 경우

처음에는 찌가 화면에서 최소 8~12픽셀 이상 보이게 확대하고, 배경과 다른 밝은 찌 끝을 선택하는 것이 좋습니다.

## 다음 개발 권장 순서

1. 실제 낚시 영상 100~300개를 모아 오탐 유형 분류
2. 카메라 흔들림을 배경 특징점으로 보정
3. 찌 형태를 찾는 경량 객체 탐지 모델 추가
4. 입질 전후 짧은 영상의 로컬 저장 기능 추가
5. 여러 찌 동시 추적
6. 스마트워치·블루투스 알림 연동
7. 사용자별·찌 종류별 감지 프로필
